# SpaceEngine
게임 소개
이 저장소는 SpaceEngine이라는 이름의 2D 슈팅 게임 프로젝트입니다. Visual Studio 솔루션을 사용해 개발되어 있으며, Direct3D 9 기반 렌더링을 적용합니다. 렌더러 초기화 과정에서 Direct3DCreate9 호출과 백 버퍼 설정을 볼 수 있습니다.

개발 동기
리포지터리 내부에는 명시적인 설명이 많지 않지만, 전체 구조를 보면 Win32 기반 게임 엔진을 직접 구현하고, 다양한 무기와 스테이지, 보스전, 랭킹 시스템 등을 통합하여 C++ 게임 프로그래밍을 학습하고자 한 것으로 추정됩니다.

주요 기능
다양한 스테이지와 배경 관리
Stage1::Init 함수에서는 배경 이미지와 경계벽을 배치하고, 무기 선택을 위한 카드팩을 준비합니다.

플레이어 무기 시스템
Player::GunType 함수는 기본 총알, 샷건, 충전 샷, 유도탄, 부메랑, 더블샷 등 여러 무기 타입을 처리합니다.

UI 및 점수 계산
HP 바, 보스 HP 바, 아이콘 등을 초기화하고 점수 표시 기능을 제공합니다.

랭킹 및 이름 입력
게임 종료 후 이름을 입력해 점수를 저장하고, 랭킹 장면에서 정렬된 결과를 보여줍니다.

게임 관리 매니저
GameMgr 클래스는 스테이지 구분, 스코어, 아이템/펫 획득, 보스 등장 여부 등 전반적인 상태를 관리합니다.

사용 기술
언어/엔진: C++

그래픽 API: Direct3D 9 (D3DX)

빌드 환경: Visual Studio 2019 솔루션, v142 툴셋 사용

실행 환경
주요 코드에서 윈도우 메시지 루프와 Direct3D 장치 생성이 이루어지므로 Windows 환경에서 실행됩니다. Space.sln에는 x64/x86 두 가지 플랫폼 구성이 정의되어 있습니다.

개발 결과
기본적인 2D 슈팅 플레이가 가능하며, 스테이지 진행에 따라 적과 보스가 등장하고, 아이템을 통한 강화나 상점 장면으로의 이동이 구현되어 있습니다.

점수 집계 후 이름을 입력해 랭킹을 저장할 수 있어, 게임의 흐름이 하나의 완전한 루프를 형성합니다.

다양한 무기와 펫 시스템, 그리고 체력/보스 게이지 등 슈팅 게임에서 요구되는 핵심 요소들이 담겨 있어 포트폴리오용 학습 프로젝트로 활용하기에 적합합니다.
